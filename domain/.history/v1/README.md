# UI Domain V1 design record

This directory records the V1 design, implementation decisions, and qualification evidence.

- [ADR.md](./ADR.md) defines responsibility, authority, trust, dependency direction, and the
  candidate V1 boundary.
- [LEDGER.md](./LEDGER.md) records decisions, unresolved questions, acceptance gates, and
  qualification evidence.

The authored `schema/` and `states/` trees are the executable contract. Nothing in this history
directory substitutes for those definitions. Runtime implementation is present; deployment and a
real external issue remain separately authorized operations.
