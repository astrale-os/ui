tests remain implementation evidence; this directory records intent, ownership, acceptance, and
delivery status without becoming a second runtime authority.

- [ARCHITECTURE.md](./ARCHITECTURE.md) — owners, dependency direction, and representation flow
- [ACCEPTANCE.md](./ACCEPTANCE.md) — falsifiable completion criteria and evidence
- [EVIDENCE.md](./EVIDENCE.md) — local qualification observations and delivery boundary
